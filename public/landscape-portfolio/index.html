Using this template

What you are looking at is a worked example: a study of Tadao Ando's Awaji Yumebutai, so you can see a finished portfolio before writing your own. To start yours from empty, copy the starter over the content file: cp content.starter.js content.js

  1. Open content.js. Everything on this page — your name, your profile, every project and every caption — is in that one file, and the notes at the top say what to write in each part.
  2. Put your drawings in the img/ folder, using the file names written in each project's images list. Any picture still missing is drawn as a labelled placeholder saying which file it wants.
  3. Delete the sample line at the top of the file to remove the banner.
  4. Press ⎙ PDF and choose Save as PDF. The cover, the profile and each project come out on their own page.

Click any drawing to see it full size; ← and → move through a project's images, Esc closes.

Nothing here is saved, uploaded or tracked — it is one folder of files that works offline and on any web host.
